### Vista previa de ECG-AI Serverless

## ECG-AI Serverless

**Plataforma Serverless para Análisis de ECG con Machine Learning**

Clasificación de señales ECG de extremo a extremo (~75,5 % de balanced accuracy) mediante inferencia serverless en AWS Lambda, API Gateway y Terraform, abarcando desde el procesamiento de señales hasta el despliegue de un modelo de Machine Learning en producción.

**Tecnologías:**
Python · Machine Learning · FastAPI · AWS Lambda · React · GitHub

**Botones:**
Caso de Estudio · Demo en Vivo
